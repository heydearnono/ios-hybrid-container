# 05 · Agent 架构

**主线目标**：把模型能力组装成「能替用户完成任务」的东西，而不只是聊天框。这是 AI Builder 的核心。

## 范围

- **Tool Calling** — 让模型调用 App 内的能力，端侧模型与云端模型的工具协议差异
- **App Intents** — App 能力暴露给系统与 Siri 的标准通道，是 iOS 上 Agent 的天然工具层
- **上下文管理** — 端侧模型上下文窗口小，如何裁剪、摘要、分段
- **结构化输出** — 用类型约束保证输出可解析，而不是解析自由文本
- **端云路由** — 简单任务走端侧、复杂任务升级到云端的判定与降级
- **可观测与评测** — 怎么判断 Agent 是否真的完成了任务

## 关键认识

iOS 上 Agent 的差异化不在模型，而在**能接触到什么**：App Intents、系统权限、本地数据。
调研重点应放在「能力接入」而非「提示词技巧」。

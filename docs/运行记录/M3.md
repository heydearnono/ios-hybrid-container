## 加载后生效差异表 · iOS 一列（每格填了什么及依据）

三步法两实例的自动跑在 `--probe-diff`（`App/ProbeDiffView.swift`），原件 `.probe/diff-result.txt`：

```
UA          完全不生效   基线A含标记=true 实例B改后重载含标记=false
缩放         立即生效     maxZoom 改前=3.0 改后=1.0（不重载）
JavaScript   重载后生效   基线A脚本跑=true 实例B改后重载脚本跑=true（B改前=false）
```

| 项 | iOS | 依据 |
| --- | --- | --- |
| JavaScript | **重载后生效** | `defaultWebpagePreferences` 是个对象,config 的拷贝共享同一个引用,改它的 `allowsContentJavaScript` 再重载就生效了。实测:基线 A 脚本跑=true、B 改前=false、B 改后重载=true |
| DOM storage | **不适用（无公开开关）** | iOS 一向开、没有关的开关。观察:`typeof localStorage === "object"`、`storage` 断言 PASS |
| 混合内容 | **[待确认]** | `WKContentRuleList` 拦 `^http://` 的规则已编译成功并加到 controller(配置路径已跑通),但没用真实 http 子资源跑完整三步法 —— 需要一个 http 源与网络,「事后改」那一维未实测 |
| 文件访问 | **不适用:没有公开开关** | pro 已定(iOS 靠三端一律不用 `file://` 承载达成,无同名开关) |
| 有声媒体自动播放 | **[待确认]** | `mediaTypesRequiringUserActionForPlayback = .audio` 在创建前设于 config(值类型 enum,预期与 UA 同属「完全不生效」),但没用真实有声视频实测自动播放,未验证 |
| 缩放 | **立即生效** | `scrollView` 在 UIKit 那侧、不在被拷贝的 config 里,改 `maximumZoomScale` 不重载即变(3.0→1.0)。这是本列的例外,正是 pro 说的「值得知道」的那种 |
| UA | **完全不生效** | `applicationNameForUserAgent` 是 config 上的值类型 String,拷贝各持一份,改拷贝再重载不生效。实测:基线 A 含标记=true、B 改后重载=false |

**本列不是齐刷刷「完全不生效」。** 预期(配置被拷贝 → 事后改无效)只在 UA 上成立;缩放(UIKit 的
`scrollView`)与 JavaScript(共享的 `defaultWebpagePreferences` 对象)都不在被拷贝那份里,所以能事后改。
这两格就是 pro 说的「真出现一格不是完全不生效,值得知道」—— 它意味着「不得在页面回调里改」这条对缩放与
JS 比对 UA 更要紧。

## 顺带答掉的「要试出来的」

- **`applicationNameForUserAgent` 标记拼在哪**:拼在 **UA 末尾**(`…(KHTML, like Gecko) Crab/0.1.0`)。
  注意 WebView 交出的系统 UA 是冻的 —— 报 `iPhone OS 18_7`,与模拟器实际 iOS 26.2 无关(和 Android 报
  `Android 10` 同类)。追加没替换,系统段完整保留。要和 Android / 鸿蒙逐字比时,Android / 鸿蒙那边手拼,
  iOS 这段落在末尾。
- **storage 跨会话留存**:实测成立。卸载重置后跑两遍 `probe.sh run`:第一遍 `# persist absent`、第二遍
  `# persist present` —— 带 identifier 的持久化 `WKWebsiteDataStore` 把 `localStorage` 跨启动(含重装、
  保留数据容器)保住了。

## 一处平台事实，待回流 pro

`WKWebsiteDataStore(forIdentifier:)`(iOS 17)取的是 **UUID,不是字符串**。pro 的 M3 写「以承载 scheme 名做
identifier」,落地时只能是一个与 scheme 绑定的**固定 UUID**(`CrabWebViewConfig.dataStoreIdentifier`),
改 scheme 就得换这个 UUID、等于换一个隔离域。这是平台 API 形状,归 pro 的 M3「平台事实」,我单独拎出来给你,
不自行改 pro。
